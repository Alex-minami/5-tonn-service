# 5 ТОНН — бесплатная диагностика

Адаптивный промо-сайт автосервиса «5 ТОНН» для записи на бесплатную диагностику коммерческого транспорта до 5 тонн.

**Сайт:** [alex-minami.github.io/5-tonn-service](https://alex-minami.github.io/5-tonn-service/)

## Что есть на странице

- первый экран с предложением и контактным номером;
- состав бесплатной диагностики;
- три простых шага записи;
- условия акции для новых клиентов;
- форма заявки и быстрый звонок;
- адреса в Балашихе и Коломне;
- адаптивная версия для телефона и планшета.

## Локальный запуск

```bash
npm install
npm run dev
```
