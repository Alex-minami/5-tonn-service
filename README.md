# TransSky — вакансии водителей

Адаптивный лендинг транспортной компании TransSky для найма водителей категории CE на магистральные перевозки.

**Демо:** [transsky-drivers.alex-minami.chatgpt.site](https://transsky-drivers.alex-minami.chatgpt.site)

## Возможности

- первый экран с вакансией и ключевыми условиями;
- прозрачный расчёт дохода и график выплат;
- презентация автопарка и карты маршрутов по России;
- преимущества работы, ответы на частые вопросы и реферальная программа;
- форма отклика и контактные данные;
- адаптивная вёрстка для смартфонов, планшетов и широких экранов.

## Технологии

- React 19;
- TypeScript;
- vinext / Vite;
- Tailwind CSS;
- Lucide Icons.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу `http://localhost:3000`.

## Проверка сборки

```bash
npm run build
```

## Структура

- `app/page.tsx` — содержимое страницы;
- `app/globals.css` — дизайн и адаптивные стили;
- `public/` — изображения автопарка, первого экрана и карты маршрутов.
